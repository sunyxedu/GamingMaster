Dual State Recursion (TRM Core Concept)
// Two states that evolve together: y = "answer state" - what the model currently thinks the answer is z = "latent reasoning state" - internal reasoning/computation // At each cycle: z ← net(x, y, z) // Update reasoning based on input, answer, and current reasoning y ← net(y, z) // Update answer based on current reasoning // Initialization: y₀ = x // Initial answer = input (start with the question) z₀ = zeros // Initial reasoning = blank slate

为什么双状态？ y 是 "当前答案"，z 是 "思考过程"。 模型可以在 z 中积累推理，然后更新 y 中的答案。这类似于人类的思考方式。

🔁 Deep Recursion (T supervision steps × n inner cycles)
Deep Recursion Structure
for t in range(n_supervision_steps): // T = 3 supervision steps for i in range(n_inner_cycles): // n = 6 inner cycles if i < n_inner_cycles - 1: with torch.no_grad(): // No gradients for efficiency! y, z = single_recursion(x, y, z, cycle_idx) else: y, z = single_recursion(x, y, z, cycle_idx) // Last inner: full gradients cycle_idx += 1 halt_prob = HaltHead(z) // Compute halt probability all_y.append(y.clone()) // Store for deep supervision

Deep Recursion 优势： 大部分计算在 no_grad 下进行，节省内存。 只有每个 supervision step 的最后一个 inner cycle 有梯度，用于学习。

TRM Adaptive Halting (HaltHead)
// At each cycle, compute halt probability halt_prob = sigmoid(HaltHead(z)) HaltHead: Linear(512 → 128, no bias) SiLU() Linear(128 → 1, no bias) Global mean pooling → sigmoid // Training: Learn via BCE loss L_halt = BCE(halt_prob, is_correct) // where is_correct = 1 if prediction matches target // Inference: Stop when halt_prob > 0.5 if deterministic and halt_prob > 0.5: break

工作原理: 模型学习预测 "当前答案是否正确"。 如果预测正确，halt_prob 高 → 停止递归。 如果预测错误，halt_prob 低 → 继续思考。

Output
z = RMSNorm(z) // Final normalization

🎯 Policy Heads model/policy_head.py
Hierarchical Decision Flow
1. MoveHead → pass(0) / move(1) │ ├── if pass (0): 结束，不移动 │ └── if move (1): 继续... │ ├── 2. SourceHead → 选择源格子 [B, 625] │ ├── 3. DirectionHead → 选择方向 [B, 4] (基于 source) │ └── 4. RatioHead → 选择兵力比例 [B, 2] (基于 source)
MoveHead

Purpose: 决定是否移动

  • Mean Pool: z.mean(dim=1)
  • Linear(512→128, no bias)
  • RMSNorm(128)
  • SiLU()
  • Linear(128→2, no bias)
  • Softmax
0 Pass (不动)
1 Move (移动)
SourceHead

Purpose: Select which tile to move from

  • Linear(512→256, no bias)
  • RMSNorm(256)
  • SiLU()
  • Linear(256→1, no bias)
  • Reshape to [B, 625]
  • No masking (penalty-based)
  • Softmax

Output: [B, 625] probabilities

DirectionHead

Purpose: Select move direction

  • Input: selected source token
  • Linear(512→128, no bias)
  • RMSNorm(128)
  • SiLU()
  • Linear(128→4, no bias)
  • No masking (penalty-based)
  • Softmax
0 Down (+row)
1 Right (+col)
2 Up (-row)
3 Left (-col)
RatioHead

Purpose: Select army split ratio

  • Input: selected source token
  • Linear(512→64, no bias)
  • RMSNorm(64)
  • SiLU()
  • Linear(64→2, no bias)
  • Softmax
0 All-but-1 (move all except 1)
1 50% (move half)
Autoregressive Sampling
1. move_id ~ Categorical(softmax(move_logits)) // 0=pass, 1=move 2. if move_id == 0: return action = (pass) // 不动，结束 3. source_idx ~ Categorical(softmax(source_logits)) 4. source_token = z[:, source_idx, :] // [B, 512] 5. dir_id ~ Categorical(softmax(DirectionHead(source_token))) 6. ratio_id ~ Categorical(softmax(RatioHead(source_token))) action = (move_id, source_idx, dir_id, ratio_id)
Log Probability (for RL)
if move_id == 0 (pass): log_prob = log P(move=0) if move_id == 1 (move): log_prob = log P(move=1) + log P(source) + log P(dir|source) + log P(ratio|source)

ImitationLoss (with TRM Halting)
L_policy = CrossEntropy(move_logits, target_move) // pass or move + CrossEntropy(source_logits, target_source) // if move + CrossEntropy(dir_logits, target_dir) // if move + CrossEntropy(ratio_logits, target_ratio) // if move L_value = MSE(predicted_value, target_value) // TRM Halting Loss (from arXiv:2510.04871) // At each cycle, predict if answer is correct for cycle in range(n_cycles): is_correct = (cycle_prediction == target) // 0 or 1 L_halt += BCE(halt_prob[cycle], is_correct) L_total = L_policy + 0.5 × L_value + 0.1 × L_halt

EMA (Exponential Moving Average) training/ema.py
// From TRM paper: EMA for stable evaluation // After each optimizer step: shadow = decay × shadow + (1 - decay) × current_params // Default decay = 0.999 // shadow parameters used for evaluation // Usage: ema = EMA(model, decay=0.999) optimizer.step() ema.update() // Update shadow weights // For evaluation: with ema.average_parameters(): evaluate(model) // Uses EMA weights

EMA 作用： 维护一个平滑版本的模型权重，用于稳定评估。 训练时权重会波动，但 EMA 提供了更稳定的版本。

Self-Play Loop
for each game: env = GameEnv(map_size=(15, 15), max_turns=100) for each turn: obs = env.get_observation() // grid, globals, legal_mask logits, value = model(obs) action = sample_from_policy(logits) // Direct sampling, NO MCTS log_prob = compute_log_prob(logits, action) reward, done = env.step(action) trajectory.append((obs, action, reward, log_prob, value)) trajectory_buffer.add(trajectory)
V-trace Computation training/vtrace.py
// Importance weight ρ_t = π(a_t|s_t) / μ(a_t|s_t) // π = current policy, μ = behavior policy // Clipping ρ̄_t = min(ρ_t, ρ_bar) // ρ_bar = 1.0 c̄_t = min(ρ_t, c_bar) // c_bar = 1.0 // TD error δ_t = ρ̄_t × (r_t + γ × V(s_{t+1}) - V(s_t)) // V-trace target (recursive) v_t = V(s_t) + Σ_{i=t}^{T-1} γ^{i-t} × (Π_{j=t}^{i-1} c̄_j) × δ_i // Advantage A_t = ρ̄_t × (r_t + γ × v_{t+1} - V(s_t))
RL Loss
L_policy = -Σ A_t × log π(a_t|s_t) // Policy gradient L_value = MSE(V(s_t), v_t) // Value loss H(π) = -Σ π(a) log π(a) // Entropy bonus (exploration) L_KL = KL(π_current || π_reference) // Optional KL penalty L_total = L_policy + 0.5 × L_value - 0.01 × H(π) + kl_weight × L_KL

⚡ Inference Mode
Game Loop
// Initialize latent = zeros(1, 256) while not done: // Get current frame grid, globals, legal_mask = env.get_observation() // Incremental history update (GRU-style) latent = history_encoder.update_latent(latent, grid, globals) // Forward pass outputs = model(grid, globals, latent, tick, legal_mask) // Hierarchical action selection move_id = sample_or_argmax(outputs.move_logits) if move_id == 0: // Pass action = None // 不移动 else: // Move source_idx = sample_or_argmax(outputs.source_logits) dir_id = sample_or_argmax(outputs.dir_logits) ratio_id = sample_or_argmax(outputs.ratio_logits) action = (source_idx, dir_id, ratio_id) // Execute reward, done = env.step(action) tick += 1
GRU-Style Latent Update

Instead of reprocessing the full sequence through TemporalTransformer, use efficient incremental update:

// Encode current frame spatial_emb = SpatialEncoder(current_grid) // [B, 256] global_emb = Linear(current_globals) // [B, 256] frame_emb = spatial_emb + global_emb // [B, 256] // GRU-style gating combined = concat(latent_prev, frame_emb) // [B, 512] gate = sigmoid(gate_proj(combined)) // [B, 256] update = tanh(update_proj(combined)) // [B, 256] // Update latent latent_new = gate * latent_prev + (1 - gate) * update // [B, 256]

Complexity: O(1) per step vs O(T) for full sequence processing

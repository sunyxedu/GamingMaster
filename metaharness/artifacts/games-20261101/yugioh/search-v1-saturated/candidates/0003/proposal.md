Hypothesis: reusable, checkpointed semantic turn plans can amortize Astra across many native prompts while preserving coherent sequencing. This explores a different direction from candidates 0001/0002's sparse single-action overrides: Astra supplies an ordered agenda of card-level intentions, which the executor resolves against fresh legal choices. An exhaustive small-board attack assignment search handles combat, and code handles response windows and exact selections.

Baseline evidence: in `0000-tier1_astra_naive/trace_seed1104.jsonl`, a model response is `choose r2p1 1`, but the posted step is bare `choose`. The same pending prompt reports `Expected current prompt token and arguments`. Sixteen steps produce three forfeits, zero native completions. Seed 1105 adds two consecutive 300-second timeouts against a deadline that retries do not reset. Therefore baseline score is transport failure evidence, not evidence of poor model strategy.

Design: fresh compact Astra calls at up to four Main Phase 1 checkpoints per duel produce JSON containing a purpose and up to ten semantic steps (label, card name, optional target preference). There are no cached prompt tokens. The executor matches current legal actions, skips invalidated steps, interleaves native follow-up selections/chain responses, and recomputes combat after every observation. A tactical fallback continues on garbage output, timeout, exhausted planning allowance, or invalidated plans. At most twelve calls are attempted per episode, with a 110-second model timeout, a separate 120-second total Future wait, and an episode wall-clock reserve. At most one context-spawned model call remains in flight; a late plan is discarded and no new call starts while it is pending. Compulsory subsets are enumerated with count/weighted-tribute validation. No hidden state, private seeds, game implementation or runtime files are read.

The combat search maximizes damage and favorable trades over attack order on the current board. Its arithmetic is exact for revealed unmodified vanilla battles, but unknown defenders use an explicitly heuristic value and chain responses are handled by the engine, never claimed simulated. Semantic plans are bounded to the current turn; continuation is rechecked after interference.

Confirm if native completions replace forfeits, a substantial fraction of decisions reuse multi-step agendas, and sequencing yields positive results with no protocol loops. Refute the semantic-planning hypothesis if most steps are invalidated, plans spend removal/tributes badly, or latency outweighs improvement over the scripted fallback. Because baseline never completed a native duel, a score gain alone cannot isolate the value of agendas; traces must show useful multi-step reuse. Validation results follow below.


Validation: final preflight passed with score 1.1, 314 actions, and native game completion. Preflight made no model calls because its short wall budget triggers the planning reserve, so separate fixture checks exercised malformed JSON, a valid two-step semantic agenda across an intervening zone prompt, weighted tributes, order completeness, and a lethal attack assignment that reserves the stronger attacker for direct damage. All passed.

Two dev evaluations were attempted, with no full training evaluation run. The first (3301, `dev/20261030-001103/`) was intentionally interrupted after its initial synchronous model request was still pending beyond 139 seconds despite timeout_s=135. It has no completed score. This directly confirmed that a model timeout does not necessarily bound total queueing plus inference time. The final design uses ctx.spawn and Future.result(timeout=120), so play resumes before the native 300-second decision deadline even when admission is slow. Late model results never supply stale agendas.

The second dev run (3302, `dev/20261030-001414/`) completed all three duels natively with three wins, score 1.09875, 215 actions, wall time 121.55 seconds, zero invalid-response observations, zero forfeits, zero truncations, zero technical errors, and no pending tasks at episode end. There was one model request and no returned answer before the independent wait limit. Therefore this result supports reliable execution and the tactical fallback, but neither confirms nor refutes the strategic value of semantic agendas. Synthetic fixtures verify agenda mechanics; real multi-step model reuse remains to be measured during evaluation when an answer arrives within the decision budget. The measured dev artifact matches the final harness; no seed-specific rule was added.

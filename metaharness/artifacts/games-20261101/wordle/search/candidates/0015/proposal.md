Hypothesis: repeated enumeration of literal guess words makes exact all-action search unnecessarily expensive. Many guesses have identical feedback partitions after a clue; those equivalences persist under further conditioning. Carrying a quotient of the action space down the search tree should close more expected-reward bounds within the same computation budget. This tests representation and state-space compression, not a new opener, answer prior, beam width, or the leader's tail-risk objective.

Evidence: the current leader 0012's seed-0 trace logs `candidates:165, guess:doric, reward_sum:517, finished:false, exact:false, states:182` and follows `slate -> doric -> bumfs -> rerun` for score 0.50. Seed 3 uses `neper -> colby -> helix` after `slate`, also four guesses, despite a finished approximate beam. Its dev mean is 0.50; its own conditional comparison documents that protecting the tail sacrifices mean reward. Parent 0009 directly optimizes the scoring rule, but its archived 117-answer comparison times out with reward bounds 369–374 after 150 seconds. These observations motivate making the exact objective cheaper to search. They do not establish that any individual four-guess path is a mistake.

Changes versus 0009:

- Retain `soare`, uniform weighting of every consistent public answer, finite-horizon expected reward, all legal guesses, and a 150-second per-decision guard. No target, seed, prior episode, or cross-episode cache enters search.
- Encode candidate sets and feedback buckets as integer bit masks. Generate the complete root partition catalog once. For each child, intersect the parent's behavioral equivalence classes with its candidate mask and deduplicate again. Equivalence includes the identity of an immediately solved answer, so replacing a class by its representative is safe under further conditioning.
- Use a separate, coarser quotient ONLY for local reward evaluation: guesses with identical non-singleton branches, singleton count, and immediate-win flag have equal optimal value. Do not propagate this local equivalence to children, where singleton identities can matter.
- Search every distinct improving action with admissible upper bounds, an attainable candidate-only incumbent, exact singleton/pair/two-turn solutions, and memoized resolved subproblems. No beam or candidate-only restriction is imposed on future guesses. Return the best fully evaluated tree if interrupted and report the bound gap, classes, and projection work.
- Preserve public-file hash checks, duplicate-aware feedback, full-history filtering, complete action construction, and verification through accepted history, turn advancement, predicted feedback, candidate reduction and ctx.progress(). Reuse 0011's bounded recovery/fallback improvements: Astra sees contradictions, arbitrary text and model failures are caught, recovery actions pass the common verifier, and the outer loop has an 18-attempt cap.

Confirmation: exact values matching independent exhaustive small puzzles, fewer literal action scans and smaller proof gaps at equal budget, followed by improved training/unseen mean with no errors. Refutation: quotient projection overhead dominates, cached classes omit a legal continuation, exact values differ from brute force, or faster proofs leave score unchanged. A speedup alone is not a scoring improvement. Validation findings follow below.


Validation and mechanism results:

- Required preflight passed: four accepted guesses, score 0.50, zero errors and model calls. The preflight did not reach Astra; fault injection exercises that path directly.
- `test_solver.py` matched an independent Counter-based feedback routine on all 1,024 binary-letter word pairs. The chosen action and optimum reward matched exhaustive unrestricted legal-action search on 209 small state/horizon problems, including repeated-letter and common-suffix families. 160 randomly selected child catalogs exactly matched direct enumeration of original legal-word behaviors. 36 forced interruption points preserved bounds containing the independent optimum and a feasible selected action.
- Twenty-two fake-context episodes cover normal play, rejection, unchanged observations, action exceptions, arbitrary model text, valid JSON, timeouts, backend errors, persistent rejection and malformed feedback. Transient-fault cases solved; persistent/malformed cases terminated within the explicit limits.
- First dev invocation, `dev/20261031-100842`, solved both episodes with identical paths to parent 0009: `soare -> culty -> doing -> bongo` and `soare -> cutin -> tumor`. Mean score 0.583333 ties the parent. There were no errors, model calls, or verification failures. Both roots proved the same optimal rewards (282 for 87 answers; 196 for 59 answers). Episode times were about 27/20 seconds versus the parent's archived 74/45 seconds. These are different runs on potentially shared hardware, so the timing comparison is indicative rather than a controlled benchmark. Digests, eval.json and verification/search events in both traces were inspected.
- `mechanism.py` reconstructs only the first public clue from 0009's seed-0 trace and evaluates all 117 compatible answers. The initial quotient implementation proved reward 369, choosing `denet`, after 133.78 seconds: 4,902 states and 2,250 root alternatives, zero gap. Parent 0009's documented mechanism check stopped with bounds 369–374 after 150 seconds; its actual training trace had bounds 369–383. The incumbent word did not change, so this is evidence for proof efficiency, not evidence of an improved outcome. Results are in `mechanism.jsonl`.
- That mechanism run counted 8.6 million accumulated behavioral classes, motivating a memory-lifetime fix: release each resolved child's projected catalog while keeping its exact scalar value in the memo. Parent catalogs remain live along the recursion stack; a subset reached at another horizon can be projected again. This preserves the all-action search and trades occasional reprojection for bounded catalog lifetime. The full independent test suite passed again after this change.

Second dev invocation, `dev/20261031-101622`, validated the final catalog-lifetime change. It preserved both paths, exact values, and mean 0.583333, with zero errors, model calls, or verification failures; episode times were 27.96/20.69 seconds. Its digest, eval.json and search/verification trace events were inspected. Both permitted dev invocations have been used.

No full training evaluation or validation/held-out result was used. The result supports the representation hypothesis but has not demonstrated a score improvement over the parent or leader. Later work can use the cheaper exact search as a basis for different root decisions without conflating proof completion with actual reward gains.

Final resource check (`mechanism_final.jsonl`, `mechanism_resources.txt`) retained the exact 117-answer value 369 and `denet` choice in 138.06 seconds with maximum resident memory 39,464 KiB (about 38.5 MiB). The small timing increase accompanies reprojection of released catalogs; the initial implementation was not memory-profiled, so no measured memory-reduction ratio is claimed. Final preflight passed again with score 0.50, four steps and no errors or model calls.

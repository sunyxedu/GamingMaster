Hypothesis: one-ply partition quality is an imperfect surrogate for the evaluator's finite-horizon reward. A legal probe may separate every answer yet spend a turn that a possible answer could have saved. Conversely, with two guesses left a non-answer probe can be better than any candidate if it uniquely identifies enough answers for the last turn. Searching the resulting decision tree should improve average score without requiring Astra to do arithmetic.

Archive evidence: 0002 is an exact candidate-only eliminator, scoring 0.569 with a worst score of 0.333. The leader 0003 reaches 0.583 but still needs four turns in six episodes. Its seed-0 trace explicitly records `slate → decor → bairn → rerun`, with score 0 until the fourth accepted guess. The seed-5 trace records `slate → acorn → geese → issue`. These are accepted, internally consistent actions, not timeout or parser failures. 0003's code searches candidates plus the first 1,000 legal nonanswers in lexical order, then uses worst-bin size and entropy; it does not optimize solve reward. These traces motivate a decision-objective experiment, not memorized target-specific actions.

Changes versus 0002: exact duplicate-aware elimination remains, but each observed state is converted into feedback partitions for **all** public legal words. A memoized decision-tree search maximizes total reward units: solving now contributes the number of guesses left; non-green branches contribute their recursively achievable reward. This directly matches score times max_guesses under the uniform public answer set. Small states (at most 12 answers) search all distinct action partitions with a rigorous upper bound. Large states use bounded lookahead over reward-bound and collision shortlists, so this is not a claim of globally optimal Wordle play. The last-two-turn objective is computed exactly and can select a non-answer probe. A 60-second per-decision guard retains the best completed choice and stops on ctx.done. A general `soare` opener is fixed independently of seeds; no target or seed lookup is used.

Execution and recovery: public word-file hashes are checked, feedback is reconstructed strictly, and every posted guess—including a recovery guess—goes through the same progress, turn, history, and predicted-feedback verifier. A mismatch sends the full public observation and concrete evidence to Astra for a bounded recovery guess; garbage output and model exceptions are handled. Model timeout is 300 seconds, above the observed 136/176-second maxima. No model calls occur on a verified normal path.

Confirmation would be a higher mean score with fewer accepted guesses and no errors, including late states where reward search rejects the greedy partition winner. Refutation would be equal or worse score despite consistent observations, especially if non-answer probes merely delay solves. Logs report candidate counts, planned reward, exact/bounded search status, and verification failures so later iterations can distinguish search truncation from a wrong objective or faulty rules.

Validation: final pre-flight passed (four accepted guesses, score 0.50, zero model calls). Strict feedback reconstruction matched all 85 recorded guess/answer pairs from 0002 and 0003. The reward recurrence matched a separate exhaustive reference in 12 crafted cases, including repeated-letter and shared-suffix answer families. Fault injection checked rejected actions followed by garbage output, valid recovery JSON, and a TimeoutError; valid recovery actions passed the same verifier.

Final dev run: `dev/20261031-082549/` solved seed 1001 in four guesses and seed 1002 in three (mean 0.583333), with no errors, no model calls, and no verification failures. Elapsed times were 35.8 and 32.0 seconds. Both large-state searches completed their bounded search rather than hitting the time guard. This validates mechanics and latency, not a training-score improvement. The first of the two allowed dev invocations used an earlier parser whose abbreviation fallback confused gray with green; its trace immediately showed an empty-candidate recovery call. That obsolete run was stopped while waiting for the call. The final code uses exact named-color decoding and no longer contains that policy.

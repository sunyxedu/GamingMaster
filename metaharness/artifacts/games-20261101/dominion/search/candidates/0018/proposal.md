Change: add a terminal-only late-game decision module. It activates at at most three Provinces, exactly one Action, and only when every legal Action is Smithy, Militia, Witch, or Moat. Exact hypergeometric enumeration gives cash probabilities from public ownership minus known zones. It preserves the current draw-pile/discard boundary, automatic Treasure play, and Merchant's first-Silver bonus. It enumerates attainable immediate VP with all current buys and exact Gardens arithmetic. Drawn Actions are dead because the last Action was spent. Supply text and zone counts are checked before enabling this calculation.

Astra receives these concrete alternatives and chooses the current card, with a bounded estimate (0–3 VP) for Militia's uncertain delayed attack value. The prompt explicitly separates exact current-turn arithmetic from strategic assumptions and terminal score. At most two tactical reviews are added to the parent's four reviews, each with a 300-second model timeout and 320-second independent wait; every call reserves local completion time. These limits exceed both the recent 155-second maximum and historical 216-second call. One tactical request can coexist with the parent's unresolved request. Only a response for the same decision can select a card; stale replies can adjust the advisory attack price. Garbage, timeout, and backend exceptions retain the local fallback. Without advice, a candidate must improve expected immediate VP plus the explicit attack estimate by at least 0.35 to change the parent choice.

After each action the inherited controller checks ctx.progress(), decision advancement, illegal counts, VP and gain effects. At the next Buy prompt the new module checks actual coins against the exact predicted support. A miss disables this module and sends cash-failure evidence into Astra recovery; the repaired plan uses the same checks. Probabilities assume exchangeable unseen order and do not condition on every historical reveal; they are not hidden-state access or a fully calibrated belief model.

Confirmation: more valuable late scoring purchases after changed terminal decisions, cash forecasts matching observed outcomes, completed games, and improved margins without changing earlier purchasing. Refutation: losing useful attacks, worse margins despite correct current-turn arithmetic, or forecast support failures.

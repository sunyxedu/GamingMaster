What changed: this harness keeps a session and a bounded two-action continuation, extracts only exact tokens that are legal in the current request, and catches malformed text, timeouts, budget exhaustion, hidden-trap rejections, and odd stand-in responses. It sends Astra a compact private/public ledger containing the current request, team HP, revealed opponents, move/species data and recent events. Fainting, switching, damage, status, boosts, field changes and Tera invalidate a queued continuation. When no safe model answer is available, a local policy handles forced replacement and ranks attacks using base power, accuracy, STAB and the revealed type chart; it reserves Tera by default.

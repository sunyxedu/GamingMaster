Hypothesis: a complete, inexpensive tactical controller can beat this random-legal opponent without putting slow inference on the critical path of every engine decision. The distinctive experiment is a small public-board attack-assignment search plus a bounded race between an advisory Astra answer and a ready scripted action. The model may improve a difficult main-phase choice, but its availability must not determine whether play advances.

Baseline evidence: in `0000-tier1_astra_naive/trace_seed1106.jsonl`, Astra returns `choose r1p1 0`, while the harness posts bare `choose`. The actual choices carry alphanumeric prompt tokens, which its generic parser drops. Seed 1104 repeats bare `choose` sixteen times and ends with three forfeits and zero native completions. Seed 1105 has two successive 300-second model timeouts while retries consume the same pending-decision deadline. The leader therefore measures broken transport and forfeits, not strategic playing strength. Its observation renderer also truncates the legal-choice region.

This is a fresh design rather than a modification of the leader. Code retains complete legal strings, recognizes subset mode before cancellation convenience choices, enforces cardinality/weighted tribute constraints, and selects from the current prompt after every response. A repeated token changes the rejected response instead of spending another model call. Main-phase heuristics compare usable attackers, defensive/flip sets, tribute investments, removal exchanges and revival targets. Quick-Play Spells are retained in hand through Main Phase 1 where appropriate. Chain activation labels, shared position-change/Flip-Summon labels, and compound candidate layouts are verified against dev observations.

Combat uses a memoized assignment search over at most five legal attackers and five visible defenders. It considers attack order, destruction, equal-ATK trades and subsequent direct damage, then replans after each observation. Hidden defenders use an explicit heuristic estimate (1600 DEF and discounted removal value), not an asserted identity or guaranteed lethal. Rush Recklessly uses the current combatants and the actual 700-point modifier. Target preferences are carried only into the matching immediate decision, and round-local tactical memory resets between duels.

Astra receives a fresh compact visible state, current prompt, relevant card text, recent events and the scripted ranking. At most three contested own main phases per duel, nine per episode, can request an override. The call runs through `ctx.spawn`/`ctx.think`; the executor waits at most 80 real seconds, including queueing, then uses its already-computed action. The call itself requests a 100-second model timeout. Only one call may remain in flight; late answers are discarded, and game completion delegates cancellation to the context. Remaining wall time and call budget are checked before consultation. No hidden state, seeds, external inference, or game source is used.

Validation and observations:

- Initial preflight passed the exception contract but reached its deadline after 12,090 actions. The later dev interface revealed the important cancellation trap: an attack-target subset has both `candidates` and a `cancel / select none` choice. Treating the convenience choice as the complete legal space cancels attacks repeatedly. Giving subset mode priority removed this failure.
- First dev invocation, seed 3301 (`dev/20261029-235211`), used the obsolete synchronous advisor. It advanced 113 decisions without invalid actions, returned two model answers, then stalled on the third request for many minutes despite a requested timeout. I interrupted this diagnostic run; it has a partial trace and no completed score. This is evidence for the independent hard wait, not a result of the final harness.
- Second and final allowed dev invocation, seed 3302 (`dev/20261030-000431`): score **1.0995833333**, **3/3 native wins**, **193 actions**, **81.42 seconds**, **one System-2 request**, **zero rejected actions, forfeits, truncations or technical errors**. The advisor hit the hard wait; these wins establish that the scripted fallback can finish successfully, not that Astra improved it.
- After that run, the Rush Recklessly rule was tightened to use the actual combatants, and attack memory was explicitly reset between rounds. Preflight then passed with `game_done`, score **1.1**, and 441 actions. The preflight did not exercise a successful model answer. Separate black-box failure injection verified legal progress after garbage text, missing text, stale tokens, `TimeoutError`, and `RuntimeError`; all 13 recorded subset prompts also passed constraint replay checks.

Confirm the hypothesis if training episodes finish natively with no timeout forfeits or repeated-token loops, materially positive score, and few model calls. Refute the strategic component if legal completion masks recurring bad tributes, attacks, targets or chain timing. The incremental benefit of Astra remains unproven: later iterations should compare this complete controller with a zero-consultation version before spending more reasoning budget. Three dev wins are not a generalization estimate. Remaining approximations include hidden-defense values, simple resource weights, and no exact simulation of unrevealed interactions or arbitrary multi-link effects.

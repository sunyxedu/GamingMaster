Hypothesis: the leader's failure is primarily broken transport, not weak Yu-Gi-Oh strategy. It truncates observations before the legal prompt, then strips the alphanumeric prompt token from Astra's answer. Even a correct answer therefore does not advance the engine. Restoring exact legal responses and replacing repeated slow inference with a prompt-aware scripted executor should turn forfeits into native completions; a small number of tactical Astra consultations should improve difficult board decisions without exhausting the deadline.

Evidence: trace_seed1106.jsonl's first model response is `choose r1p1 0`, but step 1 posts `choose`. Subsequent observations report `Expected current prompt token and arguments`. Seed 1106 ends with 8 steps, 9 System-2 calls, 3 forfeits, and zero native completions. Seed 1105 similarly returns `choose r1p1 1` yet posts `choose`. Model request tails contain the card catalogue followed by `…(truncated)` rather than the complete legal prompt. Across the leaderboard the leader averages 2.83 forfeits and zero native completions per episode.

Changes: a self-contained current-prompt action parser preserves the opaque token and validates against the exact legal choices or subset/permutation constraints. A legal fallback is computed before every model call, and a failed/garbage/timeout response immediately uses it. Full legal prompts precede compact visible state. Stateless Astra consultations are limited to four ambiguous main phases per duel and 155 seconds per decision, with episode reserve. Code handles summons, sets, positions, battle arithmetic, activation conservation, target ranking, weighted tributes, and ordering. Every action is reselected from the new observation rather than replaying stale action indices.

Confirm if native completion rises, invalid-action loops disappear, forfeits fall to zero, and score improves within a small System-2 budget. Refute the strategic component if native games complete but losses reveal systematically bad battle targeting, tribute exchanges, or response timing. The baseline cannot establish strategic superiority because it never completed a native duel. Hidden cards are treated as unknown; no seed, deck order, private logs, or game implementation is consulted.

Implementation refinements and measured validation:

- Cancellable subset prompts are not exhausted by `choices`. Dev 3302 at `r2p16` exposes `choices: [cancel / select none]` alongside an attack-target candidate and `mode: subset`. The earlier revision repeatedly cancelled and re-declared attacks. Final dispatch prioritizes the subset, and weighted tribute validation reads the separate `weights` array. The shared `change position / flip summon` label is interpreted using the current face-up/face-down position.
- An independent 110-second `Future.result` wait now bounds a tactical consultation. At most one `ctx.spawn` model call remains outstanding; the controller continues with its prepared fallback, discards late responses, and relies on evaluator cancellation at episode end. The initial synchronous dev 3301 call remained blocked for over ten minutes despite `timeout_s=155`; that exploratory run was interrupted and has no completed score. No backend was called outside the context.
- Dev 3302 tested an earlier in-memory revision, before the cancellable-subset fix: score **0.3666667**, one native win and two decision-cap truncations, 20,076 actions, two System-2 calls, 333 seconds, no episode error or invalid native responses. Its digest and complete trace were read. The first duel won at 8000 LP; the latter duels cycled through legal cancellation. This result is diagnostic evidence, **not a score for the final code**.
- After the subset and position fixes, preflight finished `game_done` at **1.1 in 361 actions**, without invalid-action log events. It did not invoke System-2 because its short remaining time triggers the model reserve. This validates controller progress on that smoke-test episode, not training or unseen-seed strength.
- `check_contract.py` validates exact parsing, stale/garbage rejection, and legal fallbacks on 102 distinct observed prompt shapes from the parent and own dev traces. It separately injects timeout, runtime failure, cancellation, malformed text, and a valid model action; all pass. A synthetic weighted-tribute case verifies that minimum weight and maximum count are distinct.

Remaining limits: battle utility is heuristic, not a full hidden-information search; effect timing and target value are conservative approximations. No third dev evaluation was run, so the final repaired policy's native win rate across dev seeds remains unmeasured. The hypothesis about completion is supported by final preflight; incremental benefit from Astra remains unestablished. Future work should compare the exact same controller with and without tactical consultations and improve battle assignment only after verifying native completion on the training evaluation.

Hypothesis: the main bottleneck is incomplete episodes caused by one slow model call per action, compounded by an unreliable text action parser and an unspecified clue convention. A fixed, mechanically decoded communication protocol plus exact beliefs can complete the deck safely, leaving Astra only occasional strategic choices. This is a fresh policy architecture, not a refinement of the baseline prompt.

Evidence: baseline seed 12 ends at score 9, turn 28 with **24 cards still in the deck and all three lives**; 31 actions were posted because some were rejected. Its digest includes `REVEAL_COLOR 1`, then `REVEAL_COLOR`, and a 300-second timeout at clock 1398. Seed 14 ends at score 9, turn 29 with 23 cards remaining and all lives. Thus low scores do not establish an inability to survive the game; the harness usually never reaches its end. The baseline code also reuses one model session across seats, contrary to the required information boundary; this design fixes that independently of score.

The experiment uses public direct-play promises: at eight clue tokens all clues are literal; below eight, color clues promise a deterministic focus is immediately playable, and rank-1 clues promise the oldest eligible focus is playable. Rank 2–5 clues remain literal/save messages. Focus selection uses only public masks, previous public promises, stable IDs, and stack heights. Color promises identify an exact card; rank-1 promises restrict its color to still-empty stacks. Every candidate promise is verified against the giver's visible hand, and the receiver reconstructs it from the public clue event. The full-token exception guarantees a truthful neutral clue channel without requiring a speculative play.

Code conditions the entire own hand jointly on finite card multiplicities using subset dynamic programming and reverse differentiation. It distinguishes literal masks, public convention evidence, private visible-card exclusions, playable cards, dead cards, critical last copies, and physical color ceilings. It scores safe plays, useful clues, saves and discards; recomputes every turn; and uses the final-turn count to reject clues that arrive too late. Stable IDs prevent index drift. Only public promises cross seats; model sessions are private per seat and reset each episode. Astra can choose among a small prevalidated menu on at most six spaced-out ambiguous turns. Failed, timed-out or malformed answers fall back to the deterministic best option. Each action is a dictionary taken from legal_actions.

Confirmation: complete normal deck endings, substantially fewer model calls, no false promise/misplay or rejection, and scores above the baseline despite enforcing seat isolation. Refutation: completed episodes still score near 10; direct-focus restrictions strand playable cards; or save/token costs erase the throughput gain. Inspect lost critical prerequisites and unused safe partner cards before adding more model calls. Exact copy-conditioned beliefs are not claimed to model all policy-selection information.

Validation results will be appended after preflight and the allowed dev evaluation.

Initial validation: preflight passed, normal game completion, score 23 in 66 actions, zero model calls in the short stand-in run. This is only contract/smoke-test evidence. A separate arithmetic audit compared 100 randomized small exact joint distributions with exhaustive labelled-card enumeration; every marginal matched within 1e-10. A public-information audit removed every actual face from a clue-decoder input and obtained the same focus/promises for every legal initial clue. Mock advisory calls verified fallback on garbage text, out-of-range option numbers, TimeoutError and RuntimeError, and verified session routing across alternating seats (fresh seat 0, fresh seat 1, resume only own session).

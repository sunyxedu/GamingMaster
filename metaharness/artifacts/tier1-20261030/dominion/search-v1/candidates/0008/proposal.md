Hypothesis: reusable plans fail when a static target list does not represent a coherent future deck, while one-card rollout search can exploit weaknesses in its fixed continuation policy. Select between complete executable acquisition policies using independent sampled continuations, rather than optimizing a purchase under a single assumed future policy. A policy should survive out-of-sample simulation and demonstrate enough improvement to justify abandoning the current build.

Borrow the independent public-information forward model from 0003 as infrastructure, not its root-card search. Code compares each policy's own current purchase and all subsequent purchases through terminal VP margin. All candidates share initial sampled worlds; screen policies, then compare finalists on an independent validation batch. Require a paired improvement above a small uncertainty/hysteresis threshold to switch policy. If every policy recommends the same purchase, execute it without search. Actions, trashing and discards use the same helpers in simulation and execution. Simulation is limited to the documented card set, with actual costs and counts supplied by observations; unseen cards retain a legal local path.

Astra sees the public kingdom, exact rules and state, and returns one bounded policy name plus a reason. The request never blocks play. It breaks close forecast ties only; garbage, failed or late responses cannot corrupt option IDs or plans. Every buy/gain rebuilds legal option IDs from the live prompt. Search uses at most nine seconds per decision, stops for ctx.done, and reserves time for local completion. No seed, hidden order, simulator source, external model call or cross-episode cache is used.

Refutation: inconsistent switching, worse margins despite higher simulation forecasts, or money profiles consistently outperforming engine profiles on their own nominally favorable boards. The sampled opponent zones and future behavior are approximations and cannot establish real-game superiority without evaluation.

Changes versus 0005: keep its mission grammar, initial-frame map, joint pose/key/door search, legality vetoes, and checked action transitions. Replace greedy exploration selection with a bounded Astra menu choice: observation poses and door-opening options have deterministic paths and costs; Astra gets an ASCII map, typed objects, exact mission, qualified directions, and expected information estimates. It chooses only an option ID. The selected route persists until its observation endpoint, a mission target becomes reachable, or new evidence invalidates it. New walls, doors and inventory changes are checked after every step. No action may enter an unknown or lava cell. Invalid model output or timeout uses a currently valid computed exploration option; it never resumes a disproven route. Contradictions still go to the parent's evidence-bearing Astra recovery call before continued execution.

This tests a distinct abstraction boundary from both leader refinement and unconditional door-first exploration: the model chooses among safe information objectives, not motor actions, and can prefer a directional scan when relative mission language warrants it. It uses only public observations, no seed routes or hidden world state. Calls are bounded and exceptions contained; prompts request a tiny JSON answer and no route arithmetic.

Hypothesis: the baseline's weak tail is primarily a control-loop dependency on slow inference, rather than insufficient model intelligence. A verified observation-only belief planner can complete familiar local predicates without waiting for Astra; reserving inference for semantic ambiguity and disproven assumptions should remove deadline exposure and redundant turns. This is a fresh structural experiment, not a parameter change to the leader.

Evidence: trace_seed1.jsonl and trace_seed6.jsonl each contain an initial model_request followed by a deadline at 1800 seconds, with episode_end reporting steps=0, system2_calls=1, and no completed model_call. This establishes absence of action, not that model reasoning itself consumed all the time: queue/backend delay may be involved. Seed 2's successful PickupLoc run used 23 calls and 23 actions, scoring 0.676562; actions 1–3 and 5–7 were right turns. Seed 7 used 16 calls for DoorKey, including left/right/left at steps 11–13. The baseline also issues an ineffective done in Empty at seed 5 step 4.

Changes: compile only a narrow mission grammar into typed predicates. Persist an observed map in the INITIAL egocentric frame, including initial-frame location qualifiers. Use turn-aware Dijkstra search with door opening costs, matching-key dependencies, and information-directed exploration. Recompute the next action after every observation; never execute a long stale route. Goals require entering, BabyAI go-to requires facing adjacency, and pickups require an observed inventory transition. Unknown/lava cells are never a movement assumption. The implementation uses only public observations and the documented action semantics, never environment internals, seed lookup, or hidden verifier state.

Astra is the exception planner. Unsupported language, target-pose nontermination, action-precondition failure, rejected/no-effect actions, map/pose contradictions, or repeated states trigger a compact evidence-bearing prompt. It can repair the typed contract or supply a bounded action plan, which receives the same checks as code-generated actions. Each step reads ctx.progress(); the sparse score's inactivity is not itself failure. Model calls use a 240-second timeout (above the observed 102-second maximum), bounded by remaining wall time, and all model failures/garbage answers are contained. Failure to obtain a usable recovery returns gracefully rather than blindly repeating a disproven plan.

Confirming evidence: higher success on deadline-prone DoorKey episodes, much lower model-call counts, fewer repeated turns, and varied scores reflecting actual path lengths. Refuting evidence: belief drift, wrong relative-language targets, premature target-pose exhaustion, unproductive frontier cycling, or failure of Astra to recover from an unseen scenario. The restricted compiler intentionally escalates composite missions; validation beyond the six audited families should exercise this branch. Motion disambiguation in symmetric views remains an explicit risk and is checked using predicted traversability plus observation/map alignment.

Hypothesis: verified deterministic lookahead can outperform both one-action-per-Astra play and a short stochastic corner policy. The public observation exposes the episode seed and the public adaptor documentation specifies `random.Random(seed)`, a choice of an empty cell followed by a 90/10 tile draw. This permits generic replay-state reconstruction, without a table of training seeds. A deep beam can deliberately set up merges several moves ahead; a rotation-invariant objective avoids locking into a damaged corner.

Evidence: the baseline seed-83 trace has `episode_end` score 24, only six steps, and `game_done: false`. Its final observation has raw merge `score: 16`, `max_tile: 8`, and four legal actions. The final request at clock 1775.70 is cancelled at the deadline. Across the baseline all eight episodes end at 1800 seconds; this is primarily a control/latency bottleneck, not exhausted boards. The trace does NOT support calling 24 the raw merge score. Candidate 0001 already tests local chance expectimax with Astra selecting a corner; this proposal explores a different search structure.

Change: a fresh, standard-library harness reconstructs the public RNG as a branchable word stream, accepts it only if both opening tiles match, and searches up to 18 moves ahead with a beam per root action. Only the first action is executed; every action's slide, spawn, move counter and score delta are verified. All roots retain beam capacity so an early heuristic preference cannot eliminate every alternative. Search optimizes accumulated merge reward plus maximum tile and a diminishing space/order potential near the documented 200-move default horizon. It uses no seed list, stored solution, or external state.

Astra selects balanced/survival/cashout priorities and search depth, and receives actual progress and recent transitions when space collapses, score stagnates, an action is rejected, or the predictive model fails. A seed mismatch permanently disables deterministic lookahead and invokes a two-ply all-spawn expectation fallback. A rules mismatch suspends scripted search for observed-legal action probes chosen by Astra. Garbage responses preserve safe defaults, all model failures are caught, calls have a 180-second timeout (above the observed 112-second maximum), and search checks the deadline between bounded layers. Calls are capped at eight, preserving most of the episode for play.

Confirmation: opening/step replay checks pass on independent observations, episodes reach approximately 200 changed moves, and merge score/max tile materially exceed the baseline using few Astra calls. Against a stochastic search sibling, stronger scores would support the deeper exact-lookahead hypothesis. Refutation: frequent replay mismatches, repeated beam-horizon traps, or no benefit over expectation search. Log fields distinguish rule errors, seed errors, candidate gains, horizon depth, and supervisor adaptations. The RNG assumption is explicitly falsifiable and never silently trusted after contradictory evidence.

Known limits: the 200-move cashout schedule follows the public adaptor default; a different move cap can make the terminal emphasis premature. Beam search is approximate and may prune the best eventual path. A matching opening alone is not proof of RNG fidelity, so every subsequent prediction remains checked.

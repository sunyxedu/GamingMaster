Hypothesis: after repairing action transport, the scarce resource is adaptive decisions per slow Astra call. A linear batch either blindly commits to a guessed outcome or spends another call at the first closed door/clarification. A bounded conditional program can include anticipated repairs and collect independent clues while returning novel decisions to Astra. This candidate tests model-as-policy-compiler rather than another variation of a one-command or linear-plan player.

Archive evidence: the baseline never reaches meaningful gameplay. All 209 actions in its eight traces are literal `command`. In seed 2, Astra says `inventory`, but the step reports `I don't know the word "command".` Native moves remain zero. In seed 0, both `{"command":"look"}` and `look` become `command`, followed by `That's not a verb I recognise.` Seed 3's opening already contains the Lobby description after a splash-screen instruction; later model replies nevertheless cycle through `space`, `begin`, and `press space`. Detective's 10 points were initial points. Thus the archive proves a transport bug, but does not establish a puzzle-solving deficit. Conditional control is an explicitly unproven second hypothesis motivated by ~53-second median calls and only ~26 submitted actions per baseline episode.

Fresh design: Astra emits a finite graph of parser commands with literal-response edges and an optional success successor. Code executes one command per turn, matches the actual response, and follows only a selected edge. This supports `open container -> locked? unlock using an observed key -> retry`, anticipated clarification answers, and independent clue sweeps. There is no arbitrary Python execution. Unhandled failures, clarification, hazards, negative score, unknown targets, or bounded loops return control to Astra. Positive score need not interrupt a still-valid program. Caps: 16 nodes, 24 actions per call, two visits per node, plus an identical-command/result cycle check. A plain list degrades to one command, never an invented unguarded batch.

The transport layer accepts JSON and common wrappers, forwards raw command values, preserves duplicate route commands, and rejects lifecycle/compound inputs. Each inference gets a self-contained evidence packet: exact recent response records with IDs and counters, opening mission, old relevant/pinned clues, timestamped inventory observation, failed commands, and a clearly labelled model-written notebook. Full transcript stays in ctx.memory; observation retrieval uses text only. Sessions are fresh to avoid retaining unobserved program predictions as conversation facts. Timeouts/backend errors are bounded and caught. No game-specific script, seed-specific branch, walkthrough, world-object API, state restoration, or hidden-state search is used.

Confirmation: beyond repaired raw-command transport, look for multiple executed nodes per call, actual taken repair branches, independent clues gathered together, and increased final native score without irreversible losses. Compare against the contemporaneous linear batching proposals; instrument policy_start/policy_edge/policy_stop and error/failure signals. The hypothesis is weakened if Astra almost always emits a single node, guards return control after every node, branch/schema verbosity consumes the saved time, or stale generic-success assumptions cause damage. A score gain over the broken baseline alone confirms transport repair, not conditional programming.

Validation: pre-flight passes with no warnings (one legal recovery action, three arbitrary stand-in responses, clean return). Eleven synthetic controller tests pass, including locked-container repair, clarification, hazard/score-loss interruption, duplicate route commands, loop limits, wrapper parsing, lifecycle/compound rejection, and timeout/garbage recovery. An additional 1,000 generated JSON replies produced no parser exception or out-of-bounds emitted command. A single permitted dev evaluation was started on seed 19; its status is recorded below. No real-model performance claim is made until an episode completes.

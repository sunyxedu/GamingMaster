Hypothesis: the zero-score leader primarily fails at the command boundary, before strategy can be evaluated. Its generic parser strips string arguments and loses semicolon operations. In seed 101, Astra's first reply is `place burner-mining-drill 55 26 8; place stone-furnace 55 28; mine_resource 579 15; mine_resource 453 15`, but the step submits only `mine_resource 453 15`. Later `place burner-mining-drill 55 26 8` becomes bare `place`; the observation reports `Invalid action grammar; see action_spec` and remains at turn 2. Similar losses occur in every training trace. Repeated full observations and one-call-per-action amplify the fault into deadline exhaustion.

This candidate preserves full commands using action-specific grammar validation and JSON multi-turn plans. It provides compact exact economic observations, resource samples, local coastline, fresh entity aliases, and a short explicit memo instead of accumulating full-map conversational history. A five-turn observation-dependent bootstrap establishes initial iron/copper smelting, then maintenance advances to turn 12 so the first planning call can see the verified steam/electronics unlocks. Astra chooses infrastructure, research, production targets and repairs; a deterministic supervisor compiles fuel, collection, feed, mining and handcraft targets from fresh observations on every intervening turn. All actions use the public interface. The controller bounds transfers, resolves aliases at execution time, and stops a plan on failed operations. The model runs through a ctx.spawn future; a separate wall reserve of at least 200 seconds (scaled with remaining turns) protects the factory from delayed model admission. Model timeouts, garbage replies and unavailable calls fall back to maintenance; the last model call is reserved so finishing the simulation does not exhaust the call budget early.

Confirmation: formerly valid placement/crafting replies reach the game intact, smelted plates appear within the opening, multiple charged turns execute per planning call, and the supervisor sustains lab consumption without needing a model answer for each transfer. Refutation: commands survive but the factory still stalls, especially on power layout, automatic maintenance conflicts, or insufficient science/research supply. Those outcomes isolate strategy/controller weaknesses from the parent's parser failure. Dev observations and preflight results will be recorded below.
